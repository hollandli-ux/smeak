# Smeak

AI English speaking practice: have real-time voice conversations with role-play characters. The mascot "Wanwan" corrects and improves your English mid-conversation. Sessions are 5/10/15 minutes, built for short daily practice.

## Features

- 30+ everyday scenarios plus custom scenarios generated by AI from a topic
- Full-duplex real-time voice with Google Gemini Live (interruptible)
- Difficulty levels; optional subtitles (pure listening mode)
- Mid-conversation correction / improvement by the mascot "Wanwan" (prompt-driven, not a separate module)
- Recordings saved locally and replayable anytime; practice history, stats, streaks
- Web app + Android app (Capacitor)

## Architecture

```
Browser / Android WebView (frontend/)
        |  HTTP + WebSocket (local relay)
        v
server.py (Python aiohttp)
   |-- /              static files (frontend/)
   |-- /api/token     issue Gemini Live ephemeral token (key stays server-side)
   |-- /api/scenario  generate a custom scenario via text model
   `-- /ws            WebSocket relay (optional, for phone clients)
        |
        v
Google Gemini API (needs access to Google)
```

## Quick start (Web)

1. Create an API key at [Google AI Studio](https://aistudio.google.com/apikey).
2. Configure the key:

   ```bash
   cp .env.example .env   # set GEMINI_API_KEY
   ```

3. Install and run:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python server.py
   ```

4. Open `http://localhost:8000`.

> Voice is powered by Google; the environment must be able to reach Google (a proxy is usually required from mainland China).

Run in the background:

```bash
nohup .venv/bin/python server.py > server.log 2>&1 &
```

For a persistent macOS service, see `deploy/com.smeak.server.plist.example` (launchd).

## Android app

```bash
npm install
npx cap sync android
cd android
./gradlew assembleDebug     # output: app/build/outputs/apk/debug/app-debug.apk
```

A debug APK is also built automatically by GitHub Actions on every push to `main`.

## Privacy

- Recordings stay on the device only.
- The API key is kept on the server (backend mode) or locally (direct mode), never shipped with the app.
- Voice/text is sent to Google Gemini for processing.
