# 获取 Google API Key 指南

Smeak 使用 Google 的语音服务，需要先获取一个 API Key 并在应用中填写。步骤如下：

## 第一步：打开申请页面
在浏览器中打开：https://aistudio.google.com/apikey

## 第二步：登录
使用您的 Google 账号登录；如果没有账号，请先点击页面上的「注册」创建一个（可用手机号或邮箱注册）。

## 第三步：创建密钥
1. 登录后进入 API Key 页面，点击「Create API key」（创建 API 密钥）。
2. 按页面提示选择或确认项目，点击「Create key」。
3. 生成后页面会显示一串密钥，形如：`AIza…`

## 第四步：复制并保存
1. 点击密钥右侧的复制按钮，复制完整密钥。
2. 请将密钥保存在安全的地方（例如备忘录）。注意：请勿把密钥发给他人。

## 第五步：在 Smeak 中填写
1. 打开 Smeak，进入右上角 设置 → 连接。
2. 在「Google API Key（直连）」栏粘贴刚才复制的密钥，点击保存。

> 提示：使用语音功能时，手机需能正常访问 Google 服务（部分网络环境需开启代理 / VPN）。免费额度对日常练习通常足够。
